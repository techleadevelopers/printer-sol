PARTE 4 — FEATURE RESET (limpar operações e voltar capital)
═══════════════════════════════════════════════════════════════

Requisitos funcionais:
- Endpoint POST /api/simulation/reset (admin auth obrigatório)
- Body: {"balance_sol": 1.0}  (opcional; default = cfg.SimulationBalanceSOL)
- SÓ funciona em SIMULATION=true. Em live retorna 400:
  "reset is simulation-only"

Comportamento:
- Transação única (BEGIN/COMMIT). Tudo ou nada.
- Apaga de simulação:
    * trades
    * transactions
    * positions
    * paper_marks
    * token_events
    * risk_assessments
    * operational_logs (opcional, com flag)
- Reinsere simulation_sessions com:
    * started_at = now
    * balance_start_sol = body.balance_sol
    * state = running
- Zera o estado em memória do engine/monitor (reserved map, tracked,
  seen, subscriptions queue)
- Reinicia o controller no estado Running (ou Stopped se o bot
  estava parado antes do reset — respeitar o estado anterior)

Segurança obrigatória:
- Requer Authorization Bearer válido (admin session)
- Recusa se SIMULATION=false
- Recusa se existir trade com state IN
  ('prepared','signed','submitted','pending','unknown')
  para não apagar operação em andamento.
  Mensagem: "reconciliação pendente; finalize antes de resetar"
- Loga em operational_logs: "simulation_reset" com payload
  {old_balance, new_balance, deleted_trades, deleted_positions}
- Rate limit: 1 reset a cada 30s (evitar clique duplo)

Frontend (front/src/pages/):
- Botão "Limpar operações e resetar" na tela de Configuração ou
  Visão geral
- Modal de confirmação: "Isso apaga TODO o histórico de simulação
  e volta o capital a X SOL. Não pode ser desfeito. Confirmar?"
- Input opcional de balance (default = valor atual)
- Chama POST /api/simulation/reset
- Ao sucesso: recarrega dashboard, mostra toast "Reset aplicado"

Implementação obrigatória no backend:
- internal/database/simulation.go: nova função ResetSimulation(
    ctx, newBalanceSOL float64) (deletedTrades, deletedPositions int, err error)
- internal/api/simulation_report.go ou novo reset.go: handler
- internal/execution/engine.go: método ResetInMemoryState() que zera
  e.reserved, cancela goroutines de confirm pendentes
- internal/tokenmonitor/monitor.go: método ResetInMemoryState() que
  limpa m.tracked, m.seen, drena m.subscriptions
- cmd/server/main.go: wire do botão do painel + novo endpoint
