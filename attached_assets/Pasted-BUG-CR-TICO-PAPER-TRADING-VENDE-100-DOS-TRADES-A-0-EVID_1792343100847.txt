2.1 FIX DEFINITIVO DO MAX_HOLD — NUNCA VENDER FLAT

Substituir em internal/positions/positions.go o bloco MaxHold por:

    if l.MaxHold > 0 {
        age := now.Sub(p.OpenedAt)
        if age >= l.MaxHold {
            // Só vende se resultado material (>+5% ou <-10%).
            // Zona morta (-10% a +5%): NÃO vende por tempo. Aguarda
            // TP/SL/trailing decidirem. Flat = perda garantida de taxa.
            if change >= holdProfitExitPct || change <= holdLossExitPct {
                return "max hold time"
            }
        }
    }

REMOVIDO: o `if age-l.MaxHold >= l.MaxHold { return "extended" }`.
Motivo: com feed quebrado, extensão só dobra o tempo até perder taxa.
Se o feed está OK, TP/SL/trailing resolvem antes de 2x MaxHold.
Nunca é correto vender a 0%.
